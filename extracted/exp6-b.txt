                      LOAD TEST ON INDUCTION GENERATOR 
AIM 
             To conduct load test on induction generator and plot the following characteristics: 
1. Efficiency Vs Output Power 
2. Line current Vs Output Power 
3. Power factor Vs Output Power 
4. Percentage Slip Vs Output Power 
5. Output Torque Vs Slip

PROCEDURE 
1. Make connections as per the circuit diagram. 
2. Set autotransformer for zero output voltage. Switch on the AC supply. Gradually increase the 
voltage from zero to the rated value using a transformer so as to start the induction machine as a 
motor. The coupled DC machine shaft also starts rotating. 
3. Switch on DC supply. Note down the reading of the connected voltmeter. 
4. Increase the excitation of the DC machine so that the generated voltage becomes equal to the 
DC source voltage in magnitude. Check if the polarity of the voltage is matching with that of the 
DC supply voltage. In case of polarity mismatch, interchange the DC machine terminals. 
5. Close the DPST switch. Paralleling of the DC machine and DC supply is done. 
6. Reduce the field excitation of the DC machine so that the wattmeter reads zero. The speed 
corresponding to this condition is called the synchronous speed of the induction machine. 
7. Note down the readings of all meters. 
8. Increase the speed in steps by reducing the motor field excitation. Note down the value at 
each time. Note down the current on the induction machine side. 
9. Repeat the procedure until the rated current is reached on the induction machine side. 
10. Reduce the current to the minimum using autotransformer. Switch off the AC supply. Then 
switch off the DC supply. 
11. From the tabulated readings, do the calculations and deduce performance characteristics.
